# Heat reference vocabulary

`heat_reference_vocabulary.txt` contains 5,000 single-word entries selected from the frequent English noun and adjective lists in [david47k/top-english-wordlists](https://github.com/david47k/top-english-wordlists), which is licensed under [Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/).

The source lists were filtered to ASCII word forms, common function words, duplicates, and the application's configured guess safety blocklist. Entries are interleaved by source frequency. This is a modified selection of the source lists; attribution and license are retained here.
